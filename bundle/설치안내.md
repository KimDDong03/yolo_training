# 단독망 설치 안내

인터넷이 없는 PC 에 YOLO 학습 콘솔을 설치하는 절차입니다.
**아무것도 깔려 있지 않은 순정 Windows 10/11 (x64)** 를 전제로 합니다.

---

## 사람이 먼저 준비해야 하는 것

### 1. NVIDIA 그래픽 드라이버 — GPU 를 쓸 거라면 필수

**이건 우리가 패키지에 넣어줄 수 없습니다.** NVIDIA 배포 정책상 드라이버 설치 파일을
직접 받아 함께 반입해야 합니다.

- <https://www.nvidia.com/download/index.aspx> 에서 대상 PC 의 GPU 모델에 맞는 드라이버를 받으세요
- CUDA 12.8 을 쓰므로 **드라이버 527.41 이상**이 필요합니다 (최신 버전 권장)
- 받은 `.exe` 를 `prereq\` 폴더에 함께 넣어 반입하고, `install.ps1` 을 실행하기 **전에** 설치하세요

> **CUDA Toolkit 은 설치할 필요가 없습니다.** torch 휠이 CUDA 런타임 DLL
> (`cudart64_12.dll`, `cublas64_12.dll`, `cudnn64_9.dll` 등)을 통째로 담고 있습니다.
> 커널 드라이버만 있으면 됩니다.

드라이버가 없어도 설치는 되지만 **CPU 로만 학습**합니다. 실사용은 어려운 속도입니다.

### 2. 관리자 권한

Python 설치와 VC++ 재배포 패키지 설치에 필요합니다.

---

## 설치

1. `bundle` 폴더와 앱 소스 폴더를 대상 PC 로 함께 복사합니다.
   (두 폴더는 나란히 있어야 합니다 — `install.ps1` 이 상위 폴더에서 앱 소스를 찾습니다)

2. PowerShell 을 **관리자로 실행**하고:

   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   cd <bundle 폴더 경로>
   .\install.ps1
   ```

3. 마지막에 나오는 점검 결과를 확인합니다.

   - `GPU 사용 가능: NVIDIA ...` → 정상
   - `GPU 사용 불가 -> CPU 로 동작합니다` → 드라이버를 설치하지 않았거나 버전이 낮습니다

4. 바탕화면의 **YOLO 학습 콘솔** 바로가기로 실행합니다.
   브라우저에서 <http://127.0.0.1:8000> 이 열립니다.

기본 설치 위치는 `%LOCALAPPDATA%\YoloConsole` 입니다.
앱이 학습 결과와 데이터베이스를 자기 폴더 안에 쓰기 때문에, 권한 문제가 없는 사용자 폴더를 씁니다.
`-InstallDir` 로 바꿀 수 있지만 **쓰기 권한이 있는 경로**여야 합니다.

## 패키지에 들어 있는 것

| 폴더 | 내용 |
|---|---|
| `prereq\VC_redist.x64.exe` | VC++ 2015-2022 재배포 패키지 (**필수**) |
| `prereq\python-3.11.9-amd64.exe` | Python 3.11.9 오프라인 설치 파일 |
| `wheels\` | 모든 파이썬 의존성 휠 (torch 포함, 약 3 GB) |
| `weights\` | 사전학습 가중치 `.pt` |
| `frontend-dist\` | 미리 빌드한 화면 (대상 PC 에 Node.js 불필요) |
| `fonts\Arial.ttf` | ultralytics 가 박스 라벨에 쓰는 폰트 |
| `requirements.lock.txt` | 설치할 패키지 목록 (버전 고정) |

### VC++ 재배포 패키지가 왜 필수인가

`torch_cpu.dll` 이 `MSVCP140.dll` / `VCRUNTIME140.dll` / `VCRUNTIME140_1.dll` 을 요구합니다.
그런데 **torch 휠에도, Python 설치 폴더에도 `MSVCP140.dll` 이 없습니다.**
개발 PC 에서 잘 되는 건 다른 프로그램이 이미 깔아둔 게 시스템에 있어서일 뿐입니다.

순정 Windows 에는 대개 없으므로, 이걸 건너뛰면 `import torch` 단계에서 설치가 실패합니다.
`install.ps1` 이 가장 먼저 설치하는 이유입니다.

---

## 패키지 다시 만들기

인터넷이 되는 PC 에서:

```powershell
.\scripts\build_bundle.ps1
```

CPU 전용 대상이면 `-Cpu` 를 붙입니다.

`pip freeze` 로 목록을 만들지 마세요. 개발 PC 에는 `opencv-python` / `opencv-contrib-python` /
`opencv-python-headless` 가 동시에 깔려 있을 수 있고, freeze 를 그대로 쓰면 그 충돌이
대상 PC 에 그대로 복제됩니다. 목록의 단일 원천은 저장소 루트의 `requirements.txt` 입니다.

## 문제 해결

**`import torch` 에서 DLL 오류가 난다**
VC++ 재배포 패키지가 안 깔렸습니다. `prereq\VC_redist.x64.exe` 를 직접 실행하세요.

**`torch.cuda.is_available()` 이 False 다**
NVIDIA 드라이버 문제입니다. 명령 프롬프트에서 `nvidia-smi` 를 실행해 보세요.
명령을 찾을 수 없다면 드라이버가 없는 것이고, 버전이 527.41 미만이면 올려야 합니다.

**설치는 됐는데 화면이 비어 있다**
`frontend-dist` 가 반입되지 않았습니다. 인터넷 되는 PC 에서 `npm run build` 후
`frontend\dist` 를 `bundle\frontend-dist` 로 복사해 다시 반입하세요.

**모델 목록이 비어 있다**
`bundle\weights\` 에 `.pt` 가 없습니다. 인터넷 되는 PC 에서
`python scripts\fetch_weights.py` 를 실행한 뒤 다시 반입하세요.
