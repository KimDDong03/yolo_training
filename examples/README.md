# 예제 데이터셋

`sample_dataset/` 은 등록 절차를 처음부터 따라해 볼 수 있는 최소 데이터셋이다.
합성 이미지라 학습 결과 자체에 의미는 없다. **동작 확인용**이다.

## 구성

```
sample_dataset/
  images/       img000.jpg ~ img015.jpg   (16장, 96x96 합성 이미지)
  labels/       img000.txt ~ img015.txt   (이미지와 파일명이 1:1 로 대응)
  classes.txt   클래스 이름 (한 줄에 하나)
```

클래스는 두 개다.

| id | 이름 |
|----|------|
| 0  | red  |
| 1  | blue |

라벨은 YOLO 형식이다. 한 줄이 객체 하나이고, 값은 이미지 크기로 정규화된 0~1 이다.

```
<클래스id> <중심x> <중심y> <너비> <높이>
```

예 — `labels/img000.txt`:

```
0 0.637769 0.603182 0.284114 0.251783
```

`train`/`val` 폴더가 없다는 점에 주의. 이 콘솔은 분할이 없으면 **자동으로 나눈다**
(기본 검증 비율 20% → 학습 12장 / 검증 4장). 직접 나누고 싶으면
`images/train`, `images/val` 처럼 하위 폴더를 만들면 그대로 인식한다.

## 등록하는 두 가지 방법

둘 다 같은 파이프라인을 탄다. 구조 감지 → 필요하면 자동 분할 → `data.yaml` 생성 → 검수 리포트.

### 1. 로컬 경로로 등록 (간단함)

화면 왼쪽 **데이터셋 추가 → 로컬 경로**에 이 폴더의 절대 경로를 넣는다.

```
<저장소를 clone 한 경로>\examples\sample_dataset
```

원본을 복사하지 않고 그대로 참조한다. 이 폴더에는 아무것도 쓰지 않는다.

### 2. zip 으로 업로드

폴더를 zip 으로 묶어서 **데이터셋 추가 → zip 업로드**에 넣는다.

```powershell
Compress-Archive -Path examples\sample_dataset\* -DestinationPath sample_dataset.zip
```

압축을 풀 때 경로 탈출(`../`)·절대 경로·심볼릭 링크 항목은 거부하고, 확장자 화이트리스트와
용량·항목 수 상한이 걸린다.

## 이 데이터로 학습 돌려보기

등록한 뒤 **새 학습**에서 이 정도면 GPU 로 1분 안에 끝난다.

| 항목 | 값 |
|------|-----|
| 모델 | `yolo11n.pt` |
| 에폭 수 | 3 |
| 이미지 크기 | 160 |
| 배치 크기 | 8 |

저장소에 함께 들어 있는 `storage/runs/20260814-124131-49d6` 이 정확히 이 설정으로 돌린
실행이다. 결과가 크게 다르면 환경 쪽을 의심해 보면 된다.
